# research

This branch contains Ramanathan Swaminathan's curated semester run artifacts for the Vaccine and Antidote projects.

Main bundle:

- `semester_runs/2026-04-16_vaccine_antidote/`

That folder includes:

- presentation-ready summary tables and CSVs
- slide graphics generated from the completed runs
- exact batch scripts used for the reported experiments
- selected `.out` and `.err` logs for completed jobs
- evaluation outputs used to compute the reported metrics

Large checkpoints are intentionally excluded to keep the branch lightweight and focused on reproducibility and reporting.
